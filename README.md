## 2. Visão Geral da Solução
* **Landing Page de Alto Impacto:** Hero editorial, narrativa de 17 anos em Planaltina-GO, coleções estruturadas, vitrine digital com filtros avançados e busca, modal de produto com guia de medidas e botão de consulta via WhatsApp.
* **Painel Administrativo "Espaço 10 Commerce":**
  1. Visão Geral (Métricas de contatos, conversão e gráficos).
  2. Gestão de Produtos (Cadastro, edição e controle de estoque com LocalStorage).
  3. CRM de Interessados (Status de leads, peças consultadas e ações recomendadas).
  4. Central de Atendimento (Chat com simulação de mensagens, respostas rápidas e ficha técnica da peça).
  5. Recuperação de Oportunidades (Fila de inatividade e régua de follow-up).
  6. Campanhas & Relacionamento (Drops, celebração de 17 anos e conformidade LGPD).
  7. Relatórios Comerciais (Exportação demonstrativa em PDF e CSV).
  8. Configurações & Guia Oficial da Marca.

---

## 3. Como Executar

```bash
# Instalar dependências (caso seja clonado em outro ambiente)
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Ou rodar o build otimizado de produção
npm run build
npm run preview
```
Acesse a aplicação em `http://localhost:5173` ou `http://localhost:4173`.
